# RBI Liabilities and Liquidity Analysis

## Overview
This project analyzes weekly balance-sheet data published by the Reserve Bank of India (RBI) to study the structure and evolution of monetary liabilities in the Indian financial system. The focus is on understanding liquidity composition, short-term fluctuations, and structural stability using official RBI data.

## Dataset
- Source: Reserve Bank of India (RBI)
- Frequency: Weekly
- Data Type: Liabilities of the RBI (Rupees Crores)
- Nature: Official central bank balance-sheet data

## Objective
The objective of this project is to examine how different components of RBI liabilities evolve over time and how short-term liquidity movements differ from long-term structural trends.

## Analysis Performed
- Data cleaning and restructuring of raw RBI Excel reports
- Time-series analysis of key liability components
- Log-scale trend analysis of major monetary aggregates
- Composition analysis of total liabilities
- Weekly percentage change analysis to identify liquidity shocks

## Key Insight
While the overall structure of RBI liabilities remains stable over time, short-term volatility in components such as notes in circulation highlights transient liquidity shocks that are not visible in long-term averages. This demonstrates the importance of high-frequency balance-sheet data for understanding monetary dynamics.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Notes
This project is descriptive and analytical in nature. It does not attempt to forecast monetary variables or infer policy causality.
